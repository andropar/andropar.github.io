Projects

Open Source Contributions

THINGSvision · 175 ⭐

Core contributor to this modular feature-extraction library for computer vision. Extracts representations from state-of-the-art models (CLIP, ViT, etc.) and is widely adopted across the vision neuroscience community.

how-to-sample · 3 ⭐

Code and experiments investigating visual-semantic coverage in neuroimaging datasets using LAION-2B. Demonstrates that dataset diversity is more critical for out-of-distribution generalization than specific sampling strategies.

CNNvis · 1 ⭐

Interactive web-based visualization tool for CNN layer activations with React/Flask interface. Developed for public science communication to help non-experts understand deep neural networks.

pysearchlight

Python-based customizable searchlight analysis tool for neuroimaging research. Enables flexible spatial analysis of fMRI data patterns.

slurmboard

Lightweight web dashboard for real-time monitoring of Slurm computational jobs on HPC clusters.
